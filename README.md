# Plain Language Marxist

An open-source platform for reading historical Marxist texts in three clearly separated layers:

| Layer | What it is |
|---|---|
| **Original** | The source text, unmodified, with its original layout |
| **Plain English** | A modern rendering of the vocabulary and syntax. It changes the wording, never the argument |
| **Explanation** | Context, terminology and commentary, always labelled as interpretation |

The guiding rule is: **simplify the vocabulary, not the argument.** The original is always one click away.
